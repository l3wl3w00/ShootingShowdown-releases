# ShootingShowdown releases

This repository holds only the release files of ShootingShowdown, a 2D multiplayer platform shooter. The game itself
is developed elsewhere.

**To play, download the game from itch.io**: <https://l3wl3w00.itch.io/shooting-showdown-2>.

Each release here has a zip of the game per platform and `latest.json`, which the game reads to offer
"Update to X.Y.Z" in its main menu. The game checks each download's SHA-256 against `latest.json` before installing it.
The files are uploaded automatically by the game's release pipeline; please don't open issues or pull requests here.
